### Custom 更新

- 新增 Claude Code Channel 接入：与 Codex 共用会话列表和页面，新建时选择会话类型及工作目录；支持发送消息、查看进展、处理本次工具审批，以及新建或恢复 Claude 会话。
- Claude 使用官方 CLI、MCP Channel 与原生启动确认，支持已启用 Channel 的终端会话接入；局域网网页无需访问码。已设置的 `claude` 默认入口会随 Sparkle 启动更新，未开启 Channel 的旧进程需退出后恢复。
- 修复 Claude 长会话只显示一条工具摘要、正文消失的问题：按真实消息数分批定位历史，不再因日志超过 4 MiB 提前停止；缓存历史位置，只增量处理追加记录。
- Codex 与 Claude 默认加载最近 10 条消息，页面最多渲染 20 条；工具调用、终端记录与 compact 压缩摘要不占消息额度，统一折叠，展开后才读取详情。双向翻页保持阅读位置，同一次滚动手势只加载一批。
- Claude 正文支持识别 URL、绝对及相对文件路径，复用 Markdown、源码和目录预览；会话链接和文件使用新标签页，目录内跳转留在当前标签页。
- Claude 与 Codex 的回复新增复制按钮，保留原始 Markdown；用户消息不显示复制按钮。兼容局域网 HTTP 网页的复制操作。
- 隐藏 Claude 终端内部提示，将本地命令和输出整理到折叠活动中；保留进展正文，精简移动端会话布局。
- Claude 的原生 `/model`、`/effort` 等终端命令仍需在电脑终端操作，网页不会将它们当作普通消息发送。

### 上次自动启动更新

- 网页新建会话不再要求先启动 Codex：选好工作目录后复用已有服务；没有可用实例时自动启动本机自定义 Codex，接入后继续提供历史恢复和新建功能。
- 自动启动仅通过命令行传入当前接入端口，不读写 Codex 配置；支持 Windows、macOS 常用安装位置，多网页并发共用一次启动，失败保留目录并允许重试，退出时只清理 Sparkle 自己启动的进程。

### 上次问答交互更新

- 修复消息问答只显示文字而无法交互：异步问题支持点选、自由输入、多问题提交及已回答状态同步，断线保留草稿；普通文字列表保持原样。

### 上次会话管理更新

- 新增 `/resume`：浏览当前项目的历史会话，可切换查看其他项目，也支持 `/resume <完整会话 ID>` 直接恢复；会话列表每页最多 20 条。
- 新建会话时，选好工作目录后自动提示恢复已有会话或另建；正在运行的会话优先加入所属实例，恢复失败时保留原会话与输入。
- 新增 `/delete`：显示会话名称、ID、目录并确认后，调用 Codex 原生接口永久删除当前会话及子代理历史；取消或失败时保留原会话，删除结果同步到其他网页。
- 会话标题栏新增项目目录按钮，在新标签页打开当前项目的只读文件浏览页。
- 修复历史列表加载时可能影响新建按钮点击的问题，并防止延迟到达的消息重新显示已删除会话。

### 已有 Codex Web 功能

- 新增 Codex 移动端网页：支持连接本机自定义 Codex app-server，浏览和新建会话、发送消息、中断任务、处理审批，以及调整模型和推理强度。
- 在应用设置中分别配置 Codex 接入端口（默认 `38471`）与手机网页端口（默认 `38472`）；网页监听 `0.0.0.0`。Codex 端需自行配置 `web_server_port`，Sparkle 不读写 Codex 配置。
- 优化长会话：默认同步最近 10 条消息，滚动时分批加载，页面最多渲染 20 条；工具调用和详情按需展开，加载历史时保持阅读位置。
- 精简移动端布局，修复输入和发送期间输入框意外收起；提供居中的回到底部图标按钮，并禁止双指缩放。
- 支持从会话打开 URL 与项目文件，浏览目录和上级目录，预览 Markdown、源码、图片与 PDF；会话链接和文件链接在新标签页打开，目录内跳转使用当前标签页。
- 支持 Windows 与 macOS 的绝对路径、相对路径、含空格路径与行列定位；文件读取限定会话项目范围，并校验符号链接真实路径。

### 已有 Custom 功能

- 新增完整配置预检：合并订阅、覆写和界面设置后，使用 Mihomo `-t` 检查；失败时保留旧核心、旧运行配置和 TUN。
- 日常配置修改优先热加载，减少重启带来的连接中断；启动参数等必要变化仍会重启核心。
- 配置应用失败时恢复上次成功配置；核心异常退出时使用上次成功配置恢复，避免加载尚未通过检查的修改。
- 覆写卡片新增状态标识：绿色“已生效”、蓝色“未生效”、红色“配置错误”，与“全局”和文件类型标签同行显示；移除“全局”的蓝点。
- JS 覆写在独立线程中执行并设置超时，执行错误会阻止配置应用。
