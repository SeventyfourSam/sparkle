### Custom 更新

- 新增 `/resume`：浏览当前项目的历史会话，可切换查看其他项目，也支持 `/resume <完整会话 ID>` 直接恢复；会话列表每页最多 20 条。
- 新建会话时，选好工作目录后自动提示恢复已有会话或另建；正在运行的会话优先加入所属实例，恢复失败时保留原会话与输入。
- 新增 `/delete`：显示会话名称、ID、目录并确认后，调用 Codex 原生接口永久删除当前会话及子代理历史；取消或失败时保留原会话，删除结果同步到其他网页。
- 会话标题栏新增项目目录按钮，在新标签页打开当前项目的只读文件浏览页。
- 修复历史列表加载时可能影响新建按钮点击的问题，并防止延迟到达的消息重新显示已删除会话。

### 已有 Codex Web 功能

- 新增 Codex 移动端网页：支持连接本机自定义 Codex app-server，浏览和新建会话、发送消息、中断任务、处理审批，以及调整模型和推理强度。
- 在应用设置中分别配置 Codex 接入端口（默认 `38471`）与手机网页端口（默认 `38472`）；网页监听 `0.0.0.0`。Codex 端需自行配置 `web_server_port`，Sparkle 不读写 Codex 配置。
- 优化长会话：默认同步最近 10 条消息，滚动时分批加载，页面最多渲染 20 条；工具调用和详情按需展开，加载历史时保持阅读位置。
- 精简移动端布局，修复输入和发送期间输入框意外收起；提供居中的回到底部图标按钮，并禁止双指缩放。
- 支持从会话打开 URL 与项目文件，浏览目录和上级目录，预览 Markdown、源码、图片与 PDF；会话链接和文件链接在新标签页打开，目录内跳转使用当前标签页。
- 支持 Windows 与 macOS 的绝对路径、相对路径、含空格路径与行列定位；文件读取限定会话项目范围，并校验符号链接真实路径。

### 已有 Custom 功能

- 新增完整配置预检：合并订阅、覆写和界面设置后，使用 Mihomo `-t` 检查；失败时保留旧核心、旧运行配置和 TUN。
- 日常配置修改优先热加载，减少重启带来的连接中断；启动参数等必要变化仍会重启核心。
- 配置应用失败时恢复上次成功配置；核心异常退出时使用上次成功配置恢复，避免加载尚未通过检查的修改。
- 覆写卡片新增状态标识：绿色“已生效”、蓝色“未生效”、红色“配置错误”，与“全局”和文件类型标签同行显示；移除“全局”的蓝点。
- JS 覆写在独立线程中执行并设置超时，执行错误会阻止配置应用。
