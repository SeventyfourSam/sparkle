### Custom 更新

- Codex / Claude Web 源码和程序已迁移为独立 AgentServer。Sparkle 设置中可选择外部程序、配置本机接入端口与网页端口，并管理自动启动、重启及退出清理；安装包不再内嵌 Web 服务。
- AgentServer 启用时自动轻量模式保留托盘，使网页服务持续可用；进程异常退出会有限次退避重试，启动失败可在设置中查看。
- 修复 macOS Electron 安装时 Framework 软链接被错误解压的问题，改用 Electron 自身使用的 ZIP 解压器。

### 已有 Custom 功能

- 新增完整配置预检：合并订阅、覆写和界面设置后，使用 Mihomo `-t` 检查；失败时保留旧核心、旧运行配置和 TUN。
- 日常配置修改优先热加载，减少重启带来的连接中断；启动参数等必要变化仍会重启核心。
- 配置应用失败时恢复上次成功配置；核心异常退出时使用上次成功配置恢复，避免加载尚未通过检查的修改。
- 覆写卡片新增状态标识：绿色“已生效”、蓝色“未生效”、红色“配置错误”，与“全局”和文件类型标签同行显示；移除“全局”的蓝点。
- JS 覆写在独立线程中执行并设置超时，执行错误会阻止配置应用。
